# 薩滿紀元 Shaman Genesis

致敬《上帝也瘋狂：開天闢地》(Populous: The Beginning) 的 3D 即時策略遊戲，使用 Three.js (WebGL) 製作，可直接在瀏覽器執行。

### 🎮 [立即線上遊玩](https://kanoan7643.github.io/shaman-genesis/)

操縱你的 **薩滿** 與部下，讓子民 **向神祈禱** 以換取法力與新法術，並用天災擊潰敵對的赤焰部族。

## 特色

- **真 3D 高清畫面**：可旋轉/縮放鏡頭、即時軟陰影、ACES 色調映射、泛光 (Bloom)、MSAA 抗鋸齒、動態水面（岸邊浪花、菲涅耳反射）
- **可變形地形**：陸橋、地震、火山會即時改變地形，並影響尋路
- **信仰系統**：
  - 子民在 **靈魂圖騰** 祈禱 → 累積法力
  - 子民在 **石像** 祈禱 → 解鎖新法術（孤島上的石像需要「陸橋」才能抵達）
- **7 種法術**：爆破、感化、雷擊、龍捲風、陸橋、地震、火山
- **敵方 AI**：會採集、建造、祈禱解鎖法術、訓練戰士並發動進攻，薩滿也會施法
- 小屋自動產生勇者；勇者會自動伐木、建造；可訓練成戰士

## 執行

最簡單的方式是直接開啟線上版：<https://kanoan7643.github.io/shaman-genesis/>

若要在本機執行，需要透過本機伺服器開啟（ES 模組無法在 `file://` 直接載入）：

```bash
python -m http.server 8000
```

然後開啟 <http://localhost:8000>。Windows 也可以直接雙擊 `start.bat`。

## 操作

| 動作 | 按鍵 |
|---|---|
| 平移鏡頭 | WASD / 方向鍵 / 滑鼠移到畫面邊緣 / 拖曳小地圖 |
| 旋轉鏡頭 | Q / E / 滑鼠中鍵拖曳 |
| 縮放 | 滾輪 |
| 選取 | 左鍵點選 / 拖曳框選，Shift 加選，雙擊選同類 |
| 選取薩滿 | 空白鍵 |
| 移動 / 攻擊 / 伐木 / 建造 / 祈禱 | 右鍵地面 / 敵人 / 樹 / 工地 / 石像或圖騰 |
| 攻擊移動 | Ctrl + 右鍵 |
| 施法 | 1–7 或點法術按鈕，再左鍵點目標（Shift 連續施放，右鍵取消） |
| 建造小屋 / 訓練所 | B / V |
| 訓練戰士 | R（或選取勇者右鍵訓練所） |
| 圖騰祈禱 | T |
| 自動工作 | G |
| 停止 | X |
| 選取所有戰士 | F |
| 暫停 | Esc / P |

## 勝利條件

消滅敵方所有子民與房屋。摧毀敵方靈魂圖騰可以阻止敵方薩滿重生。

## 專案結構

```
index.html        介面與 importmap
style.css         HUD 樣式
src/main.js       渲染器、鏡頭、輸入、HUD、小地圖
src/game.js       遊戲世界邏輯
src/entities.js   單位、建築、石像
src/spells.js     法術效果
src/ai.js         敵方 AI
src/terrain.js    地形生成、水面、天空
src/models.js     程序化 3D 模型
src/fx.js         粒子特效與合成音效
src/path.js       A* 尋路
src/config.js     數值設定
```
